# Kinbo — কিনবো 🛍️

**বাংলাদেশের শপিং অ্যাপ — কিনুন • বেচুন • আয় করুন**

Kinbo is a multi-vendor shopping app made for Bangladesh. Anyone can open an account and buy; anyone who wants to sell can create their own shop inside the app — for free.

## 📥 Download

Get the latest Android APK from the [**Releases**](https://github.com/aishagormultimidea-create/kinbo-app/releases) page — open the newest release and download the `.apk` file, then install it (you may need to allow "Install from unknown sources" for your browser once).

## Features

- 🏪 **Your own shop** — create a shop manually whenever you want to sell; your account alone never forces a shop on you
- 🗂️ **Categories & search** — every product is categorised; browse or search by name, shop or category
- 💸 **Prices in Taka (৳) only** — discounts with old-price display, stock status on every product
- 🤝 **Affiliate earning** — share any product with your code and earn the commission the seller set, when it sells
- 💳 **Direct payment** — buyers pay sellers directly (bKash / Nagad / Rocket / bank / cash on delivery). The app never holds your money
- 🛠️ **Admin moderation** — listings can be hidden and abusive shops blocked
